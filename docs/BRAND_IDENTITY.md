# Acequia-inspired visual identity

The new project uses the supplied visual direction as the canonical product identity:

- **Background:** deep navy/near-black (`#060a12` / `#0a0f1c`)
- **Primary accent:** teal (`#2DD4BF`)
- **Governance/accent:** muted gold (`#C9A227`)
- **Typography:** Space Grotesk for display; Inter for UI; monospace for technical labels
- **Motif:** an abstract architectural arch/frame inspired by the Acequia/Alhambra water-channel concept without literal architectural illustration
- **Core visual metaphor:** five independent agent channels converge into one decision basin: **PHYSICIAN DECIDES**
- **Product line:** ICU Clinical Decision Support

The identity intentionally communicates orchestration, controlled flow, provenance, and physician authority rather than autonomous treatment.
